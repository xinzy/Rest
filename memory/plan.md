# 歇会儿 · 设计方案（v1）

> 状态：设计已定稿（2026-10-27 逐题确认）；UI 原型已确认（2026-10-27）；正在按切片实现，进度见 memory/progress.md。
> 规则：本文件中的决策都已经过用户确认。实现时如需偏离，先提出并获批准。

## 1. 概述

「歇会儿」是一个常驻 macOS 菜单栏的定时休息和喝水记录工具，仅供自用。
它在工作时间内按「短 短 短 长」的节奏提醒休息：到点前先弹浮窗预告，然后全屏遮罩倒计时，倒计时结束后自动退出。它还记录每天每次喝水的时间和杯数，并提供报表。

术语：**一轮** = 一段工作计时 + 紧随其后的一次休息（完成或跳过都算）。

## 2. 已确认决策

### 2.1 定位与技术

| 项 | 决策 |
|---|---|
| 使用范围 | 仅自用；不签名公证，不上架 |
| 技术栈 | 原生 Swift：AppKit 负责状态栏和窗口，SwiftUI 负责界面内容；不用第三方依赖 |
| 最低系统 | macOS 14 Sonoma（本机为 macOS 15.7.5，Apple Silicon） |
| 界面语言 | 仅中文 |
| 名称 | 显示名「歇会儿」；工程和模块名 `XieHuiEr`；Bundle ID `com.shaozeng.xiehuier` |
| Dock 图标 | 不显示（LSUIElement），只在菜单栏出现 |
| 开机自启 | 默认开启（SMAppService），可在设置中关闭 |
| 数据存储 | 设置存 UserDefaults；记录存 SwiftData；仅保存在本机，永久保留 |

### 2.2 计时规则

- **短休息**：默认每 30 分钟休息 30 秒。
- **长休息**（可关闭）：每到第 4 轮就是长休息，默认 5 分钟，即「短 短 短 长」。按 30 分钟的间隔算，约每 2 小时一次。
- **轮次计数**：短休息无论完成还是跳过，都算一轮。长休息被跳过时计数不变，下一轮仍是长休息；长休息完成后重新计数。
- **立即休息**：类型和下一轮相同（短或长），并算作这一轮。
- **工作时间**：默认周一至周五 09:00–19:00（勾选星期几并设置一个时间段，可修改，不能跨午夜）。不识别节假日和调休，放假时手动暂停。
  - 非工作时间：不提醒，菜单栏图标变灰，面板显示下次开始的时间；「立即休息」和喝水记录照常可用。
  - 进入工作时间后，从第一次键盘或鼠标操作开始计第一轮。到下班时间后不再触发新的休息，正在进行的休息照常走完。
- **离开**：键鼠无操作达到 5 分钟（可修改）、锁屏或睡眠时，视为已经自然休息过，暂停计时；回来后重新开始一轮。如果离开的时长不短于长休息时长，长休息计数清零。
  - 例外：虽然无操作，但有程序在阻止屏幕休眠（例如正在播放视频）时，仍算在看屏幕，不判定为离开。
- **开会时自动推迟**：到点时，如果麦克风或摄像头正被任何程序使用，就不预告、不弹遮罩，之后每 60 秒复查一次；会议结束后按正常流程先预告再休息。不检测其他 App 是否全屏。
- **暂停**：可选 30 分钟、1 小时、直到明天（次日 0 点）、直到手动恢复。恢复后开始新的一轮。
- **修改设置**：立即生效，当前这一轮从头计时（轮次计数保留）。如果在休息进行中修改，等这次休息结束后再生效。App 重启后也从新的一轮开始。

### 2.3 一次休息的流程

1. **预告**：到点前 30 秒（可修改，设为 0 表示不预告），在鼠标所在屏幕的右上角、菜单栏下方弹出小浮窗，显示倒计时以及「推迟 5 分钟」「立即开始」两个按钮。浮窗不抢键盘焦点。不使用系统通知。
2. **推迟**：每次推迟 5 分钟（可修改），不限次数，每次推迟都记入报表。
3. **遮罩**：覆盖所有屏幕，包括所有桌面（Space）、其他 App 的全屏界面、程序坞和菜单栏，效果为深色毛玻璃。每块屏幕上都显示：休息类型、大字倒计时和进度环、一条随机休息建议（短休息是护眼建议，长休息是活动建议）、「💧 喝了一杯水」按钮、「跳过休息」按钮。
4. **跳过**：按钮从休息开始就能点击；按 Esc 不会跳过；遮罩显示期间拦截所有键盘输入；跳过后重新开始完整的一轮。
5. **结束**：倒计时结束时播放一声轻提示音（可关闭），遮罩自动退出，并把焦点还给休息前正在使用的 App。
6. 不自动暂停正在播放的音乐或视频。

### 2.4 喝水

- 只记杯数。每条记录保存喝水时间；当天的杯数 = 当天（从本地时间 0 点算起）的记录条数。
- 每日目标默认 8 杯（设为 0 表示不设目标）。
- 入口一：面板中的「💧 今日 x/8 杯 [+1 杯]」。点击 +1 后 5 秒内可以撤销。
- 入口二：遮罩上的「喝了一杯水」按钮。点击后只记录、不结束休息；每次休息只能点一次，点击后按钮变为「✓ 已记录 · 今日 x 杯」。
- 不单独弹出喝水提醒。面板和遮罩上显示「距上次喝水 X」，当天还没喝时显示「今天还没喝水」；距上次喝水满 2 小时后，喝水按钮高亮显示。
- 在报表中可以删除单条记录。

### 2.5 报表（独立窗口，从面板打开）

- **喝水**：近 7 天或近 30 天每天杯数的柱状图，带目标线，并显示达标天数和日均杯数；选择某个日期可查看当天每次喝水的时间，并可删除记录。
- **休息**：每天完成、跳过、推迟、自动推迟的次数；完成率 = 完成次数 ÷（完成次数 + 跳过次数）。

### 2.6 v1 明确不做

签名公证和上架、CSV 导出、iCloud 同步、节假日识别、全局快捷键、严格模式、全屏 App 检测、自动暂停媒体播放、补录喝水、按毫升计量、多语言。

## 3. 计时状态机（实现规格）

调度器是纯逻辑代码，不依赖 AppKit：输入「事件 + 当前时间」，输出「新状态 + 需要执行的副作用」，这样可以完整地做单元测试。所有截止时间都用绝对时间（Date）表示，而不是累加计时器的触发次数，因此电脑睡眠或程序卡顿都不会让计时漂移。

### 3.1 状态（自上而下按优先级判定）

| 优先级 | 状态 | 说明 | 菜单栏图标 |
|---|---|---|---|
| 1 | 休息中 `onBreak(kind, endsAt)` | 正在显示遮罩 | 实心圆 |
| 2 | 暂停 `paused(until?)` | 手动暂停 | 细圆环 + 暂停符号 |
| 3 | 非工作时间 `offHours(nextStart)` | 不在设定的工作时间内 | 圆环整体变灰 |
| 4 | 离开 `away(since)` | 判定用户已离开 | 圆环整体变灰 |
| 5 | 会议推迟 `deferred(pending)` | 麦克风或摄像头正被占用 | 细圆环 + 中心圆点 |
| 6 | 预告 `warning(pending)` | 正在显示预告浮窗 | 细圆环 + 中心圆点 |
| 7 | 工作中 `working(pending)` | 正常计时 | 进度环（剩余时间越少，弧越短） |

`pending` 表示即将到来的那次休息，包含：类型 kind、到点时间 dueAt、触发方式 trigger（scheduled 按计划 / manual 手动）、已推迟次数、是否已记录过自动推迟。

### 3.2 状态转移

| 当前状态 | 事件 | 结果 |
|---|---|---|
| 工作中 | now ≥ dueAt − 预告秒数 | 正在开会 → 会议推迟（记一次 autoDeferred）；否则 → 预告 |
| 预告 | now ≥ dueAt | 正在开会 → 会议推迟；否则 → 休息中 |
| 预告 | 点击「推迟」 | dueAt = now + 推迟时长，记一次 postponed → 工作中 |
| 预告 | 点击「立即开始」 | → 休息中 |
| 会议推迟 | 每 60 秒复查，发现会议已结束 | dueAt = now + 预告秒数 → 预告（预告秒数为 0 时直接进入休息） |
| 休息中 | now ≥ endsAt | 记一次 completed，更新轮次，播放结束提示音 → 按优先级重新判定（通常进入新的一轮） |
| 休息中 | 点击「跳过」 | 记一次 skipped，更新轮次 → 按优先级重新判定 |
| 除休息中以外的任意状态 | 点击「立即休息」 | → 休息中（类型取下一轮的类型，trigger = manual） |
| 工作中 / 预告 / 会议推迟 | 选择暂停 | → 暂停 |
| 暂停 | 暂停到期或手动恢复 | 开始新的一轮 → 按优先级重新判定 |
| 工作中 / 预告 / 会议推迟 | 无操作时长 ≥ 阈值且没有防息屏断言；或锁屏；或睡眠 | → 离开（since = 最后一次输入时间、锁屏时间或睡眠时间） |
| 离开 | 有键鼠输入 / 解锁 / 唤醒 | 若离开时长 ≥ 长休息时长 → 轮次计数清零；然后 → 新的一轮 |
| 除休息中以外的任意状态 | 离开工作时间 | → 非工作时间（隐藏预告浮窗） |
| 休息中 | 离开工作时间 | 休息走完后 → 非工作时间 |
| 非工作时间 | 进入工作时间 | 无操作时长 < 阈值 → 新的一轮；否则 → 离开（等待第一次操作） |
| 任意状态 | 修改设置 | 休息中：等休息结束后生效；其他状态：当前这一轮从头计时，轮次计数保留 |

**轮次规则**（`roundsSinceLong` 表示距离上次长休息已经过去的轮数）：

- 下一轮的类型：长休息已启用且 `roundsSinceLong ≥ N − 1` 时为长休息，否则为短休息（N 默认为 4）。
- 短休息完成或跳过：`roundsSinceLong += 1`。
- 长休息完成：`roundsSinceLong = 0`；长休息被跳过：不变。
- 离开时长 ≥ 长休息时长：`roundsSinceLong = 0`。
- 面板显示「第 roundsSinceLong + 1 / N 轮」。

### 3.3 系统检测（预计都不需要申请系统权限）

| 检测项 | 方式 | 检测时机 |
|---|---|---|
| 无操作时长 | `CGEventSource.secondsSinceLastEventType(.combinedSessionState, 任意输入)` | 每秒 |
| 防息屏断言 | `IOPMCopyAssertionsStatus` 中 `PreventUserIdleDisplaySleep` 或 `NoDisplaySleepAssertion` 大于 0 | 判定是否离开时 |
| 锁屏 / 解锁 | `DistributedNotificationCenter`：`com.apple.screenIsLocked` / `com.apple.screenIsUnlocked` | 收到事件时 |
| 睡眠 / 唤醒 | `NSWorkspace.willSleepNotification` / `didWakeNotification` | 收到事件时 |
| 麦克风占用 | CoreAudio：遍历输入设备，读取 `kAudioDevicePropertyDeviceIsRunningSomewhere` | 预告开始时、到点时、会议推迟期间每 60 秒 |
| 摄像头占用 | CoreMediaIO：读取 `kCMIODevicePropertyDeviceIsRunningSomewhere` | 同上 |

## 4. 界面

视觉以 HTML 原型为准：`design/mockups/index.html`，截图在 `design/mockups/screenshots/`。实现时按原型做，如有偏离需要说明。

### 4.1 视觉规范

- 使用系统原生控件和 SF Symbols；使用系统字体（中文自动使用苹方）；所有数字使用等宽数字。
- 强调色跟随系统设置；喝水相关的元素统一用系统青色。
- 面板、设置、报表跟随系统的浅色或深色外观；遮罩始终是深色。
- 遮罩：毛玻璃加一层黑色半透明，文字为白色；倒计时字号 72pt；进度环直径 240pt、线宽 10pt；出现时淡入 0.4 秒，消失时淡出 0.3 秒。
- 遮罩上的按钮层级：「喝了一杯水」是主按钮，「跳过休息」是次要的文字按钮，以此轻微引导用户多休息、多喝水。
- 菜单栏图标：18×18pt 的模板图，能自动适配浅色和深色菜单栏。

### 4.2 各界面要点

| 界面 | 要点 |
|---|---|
| 菜单栏图标 | 只显示图标；各状态的样式见 3.1 |
| 面板 | 宽 320pt，没有指向图标的小箭头（样式类似控制中心）。上部：进度环、剩余时间、下一次休息的类型、「第 x/N 轮」；中部：「立即休息」「暂停 ▾」；然后是喝水那一行；底部：「报表…」「设置… ⌘,」「退出 ⌘Q」 |
| 预告浮窗 | 宽 330pt，位于鼠标所在屏幕的右上角、菜单栏下方；包含倒计时环、提示文字、「推迟」「立即开始」 |
| 遮罩 | 每块屏幕全屏显示；包含休息类型、倒计时环、休息建议、喝水按钮（带「距上次喝水」）、跳过按钮 |
| 设置 | 三个标签页：通用 / 休息 / 喝水；分组表单；修改后立即保存；取值范围见 4.3 |
| 报表 | 顶部可切换「喝水 / 休息」和「近 7 天 / 近 30 天」；内容为概览卡片、图表和明细 |

### 4.3 设置项与取值范围

| 设置 | 默认值 | 范围 |
|---|---|---|
| 短休息间隔 | 30 分钟 | 5–120 分钟 |
| 短休息时长 | 30 秒 | 10–600 秒 |
| 长休息 | 开启 | — |
| 长休息频率 | 每 4 轮一次 | 2–10 轮 |
| 长休息时长 | 5 分钟 | 1–30 分钟 |
| 休息前预告 | 30 秒 | 0–60 秒（0 表示不预告） |
| 推迟时长 | 5 分钟 | 1–30 分钟 |
| 离开判定 | 无操作 5 分钟 | 1–30 分钟 |
| 开会时自动推迟 | 开启 | — |
| 只在工作时间提醒 | 开启，周一至周五 09:00–19:00 | 开始时间必须早于结束时间，不能跨午夜 |
| 休息结束提示音 | 开启 | — |
| 显示休息建议 | 开启 | — |
| 每日喝水目标 | 8 杯 | 0–30（0 表示不设目标） |
| 开机自动启动 | 开启 | — |

预告最长 60 秒，不超过最短推迟时长 1 分钟，所以推迟之后不会马上又弹出预告。输入超出范围时会给出提示，并且不保存。

### 5.2 关键实现

- **菜单栏**：用 `NSStatusItem` 加一个自定义的无箭头 `NSPanel`（内容用 SwiftUI 编写），不用 `MenuBarExtra`。原因是需要在休息开始时用代码关闭面板，还要动态绘制进度环图标。
  S1 实测确认：
  - **面板本身**：无边框的 `.nonactivatingPanel`，层级 `.statusBar`。打开后前台 App 不变。
  - **收起方式**：失去焦点、点击其他 App、按 Esc、再点一次图标，四种都会收起。
  - **菜单追踪通知**：打开和收起面板时成对发出 HIToolbox 的 begin/endMenuTracking 通知，让其他 App 全屏时菜单栏保持显示。退出也要先收起面板，否则两条通知不成对。
  - **多显示器**：每块屏幕的菜单栏上都有一个图标窗口。点击时 `statusItem.button.window` 就是被点的那块屏幕上的图标窗口，面板会出现在被点的图标下方。
  - **启动时**：刚启动时图标窗口还在排版，先在屏幕外，之后才移到屏幕边缘，所以不能在 `applicationDidFinishLaunching` 里立即按它定位。
- **设置和报表窗口**：自行管理 `NSWindow` 并用 `NSHostingController` 承载 SwiftUI 内容；打开窗口时激活 App；关闭窗口不会退出 App。
- **遮罩**：每块屏幕一个无边框窗口，窗口层级为 `.screenSaver`，`collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary, .ignoresCycle]`；内容是深色的 `NSVisualEffectView` 加 SwiftUI 视图。屏幕配置变化时重建窗口；显示前记下当前的前台 App，结束后重新激活它。
- **预告浮窗**：使用 `NSPanel`（`.nonactivatingPanel`），不会成为 key window，按钮可以直接点击。
- **主循环**：一个每秒触发的 Timer（设置 tolerance 以节省电量），驱动调度器和界面刷新。
- **数据模型**（SwiftData；枚举值以字符串形式存储，方便用 `#Predicate` 过滤）：
  - `WaterRecord { drankAt: Date }`
  - `BreakEvent { at: Date, kind: short|long, type: completed|skipped|postponed|autoDeferred, trigger: scheduled|manual }`
- **DEBUG 快速模式**：启动参数 `-fastMode YES`，把所有时长换成秒级，方便手动验证（具体参数见 verify.md）。

## 7. 风险与待实测

| 风险 | 应对 |
|---|---|
| 遮罩盖不住其他 App 的全屏空间 | S4 优先实测；不行的话尝试提高窗口层级，或改用 presentationOptions |
